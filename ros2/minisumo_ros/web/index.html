Eventos

    Señales crudas frente al filtro de Kalman

    Gris: medida cruda · verde: Kalman en el PC · arcilla: filtro del ESP32. La reducción compara la desviación estándar en la ventana visible; con el sensor quieto mide cuánto ruido quita el filtro.

    PID de cada rueda

    Velocidad de rueda en cascada bajo el control de rumbo. G,kp,ki,kd,kff

    Control de rumbo

    Mantiene el ángulo con el giroscopio y lo recupera tras un empujón. Y,kp,ki,kb

    Zona muerta de los motores

    Ciclo útil mínimo para que cada motor arranque y corrección máxima del PID. F,izq,der,trim

    Manejo manual

    Arrastra dentro del círculo o usa WASD / flechas. Suelta y el robot se detiene. Apaga el guante para que no compitan.
